# Resolving AI Integration Issues with Paperless

Configure AI settings in the web UI to enable intelligent document processing within the Paperless instance.

### Configuration Procedure

| Step | Action | Details |
| --- | --- | --- |
| 1 | Navigate to **webui** interface | Access the Paperless admin dashboard |
| 2 | Access **AI Settings** | Find the AI configuration section |
| 3 | **Turn on AI** | Enable artificial intelligence features |
| 4 | **Choose model** | Select **llama3.1** for document processing |
